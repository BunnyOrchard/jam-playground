Jam Playground

version 1.2.0 · FM-1_7010200

Power on and it is already playing. Three quiet notes rise over the song. A new boot is a new song. Four synth keys can sound at once. A fifth turns the oldest off. Eleven drums sit beside them.

Install in the browser Download the package

Chrome or Edge, with the FM-1 on a USB data cable. The installer page writes this package. Do not unplug the cable while it writes.

From a terminal, with mido and python-rtmidi: python3 tools/fm1_install.py firmware/jam-1.2.0.fwsc

If the write stalls

The package can finish writing and the unit can come back while the page is still saying it is restarting. Unplug nothing. If the screen is playing, the install finished. If the screen says it is in update mode, plug the cable in again and press Install once more. It finishes the write.

Back to stock

The install page can write M-VAVE's FM-1 V15 back. Songs stored on the unit can be lost. Installing firmware is at your own risk. Jam Playground is not affiliated with M-VAVE.
